SYSTEM COMMAND & TOOL REFERENCE

Terminal Commands:

  • ls - Lists files in current directory
  • cd <folder> - Change directory (type cd .. to go back)
  • cat <file> - Read file contents
  • rm <file> - Delete a file
  • crack <file.enc> - Decrypt encrypted payloads
  • connect <node> - Connect to a network node
  • disconnect - Instantly disconnect from current node
  • shop - Open black market to buy software & RAM
  • buy <item> - Purchase item from shop
  • save / load - Save or Load your active mode's save data
  • clear - Clears terminal screen
